Option A · chosen

Light Well

A warm bloom behind three hairline rings. Each ring answers the voice 90ms after the one inside it, so the response reads as breath rather than as a meter. Idle is a 3.8s swell; thinking contracts the bloom and drifts a single arc round the rim; done fills the core and settles.

Option B

Horizon

A single line across the lower third that bows upward with volume, with a slower echo behind it. Very quiet, very distinctive, and it leaves the whole upper screen to the transcript — but it carries "thinking" and "done" less clearly than a closed shape.

Option C

Grain Field

Twenty soft columns that lift in a travelling wave, weighted by amplitude. Legible and pretty, but the closer it gets to a real waveform the more it reads as recording hardware — the opposite of the calm we want.

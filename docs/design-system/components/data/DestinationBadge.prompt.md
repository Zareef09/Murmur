Marks whether a capture became a Reminder (moss) or a Calendar Event (plum).

```jsx
<DestinationBadge destination="event" />
<DestinationBadge destination="reminder" variant="glyph" />
```

Non-negotiable: the icon and the word ship together — moss and plum are a reinforcement, never the signal itself. `glyph` still carries a title attribute for the label.

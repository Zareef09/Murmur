The Murmur wordmark: the single letter **M**, set in the core face with the ember dot beside it. Tracked at `--ls-wordmark` (0.13em).

```jsx
<Wordmark size={30} />
<Wordmark size={22} tone="inverse" dot={false} />
```

Never bold it, never set it in another family, never add a tagline inside the lockup. Minimum clear space around the mark is one cap height.

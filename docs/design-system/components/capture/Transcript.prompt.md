Live caption of what the user is saying — used on Capture (listening) and Clarification (answering).

```jsx
<Transcript text="Remind me to call mom" partial="tomorrow at fi…" placeholder="I'm listening…" />
```

Set at 26px/300 weight: readable at arm's length, mid-stride. Cap at ~30ch and let it wrap; never truncate a sentence the user just spoke. Left-align only inside Clarification.
